# 3D asset pipeline

Runtime models are binary glTF files in `v6/models/`. They are generated by
two independent toolchains: Python signed-distance-field (SDF) sculpting, and
Blender scripts. Neither is needed to run the site.

| File | Content | Source |
| --- | --- | --- |
| `rider.glb` | Rider and scooter | `tools/rider_sdf.py` + `tools/scooter_sdf.py` / `scooter_import.py` |
| `people.glb` | Standing travellers for the hall | `tools/people_sdf.py` |
| `kit_batiments.glb` | Buildings | `blender/kit_buildings.py` |
| `kit_nature.glb` | Trees and plants | `blender/kit_nature.py` |
| `kit_monuments.glb` | Landmarks | `blender/kit_landmarks.py` |
| `kit_faune.glb` | Animals | `tools/blender/faune_blender.py` |

Mesh and material names inside a GLB are meaningful: the engine looks them up
by name (for example `haussmann_a`, `platane_b`, `peinture_menthe`). Names
containing `neon`, `feu_`, `ampoule`, `phare` or `lanterne` always glow;
`verre_lumiere`, `lampe_verre`, `vitrine_lumiere` and `hall_lumiere` glow only
at night.

## Python SDF tools (`v6/tools/`)

Requirements: Python 3, NumPy, scikit-image (`pip install numpy scikit-image`).

| Script | Role |
| --- | --- |
| `sdf.py` | SDF toolbox: primitives, blends, marching-cubes meshing, a minimal GLB writer and reader |
| `rider_sdf.py` | Builds the rider (face, bun, jacket, jeans, trainers, leather backpack) and imports the scooter |
| `scooter_sdf.py` | Hard-edged vintage scooter built from SDFs |
| `scooter_import.py` | Imports `scooter_retro.glb`: flips it to face +z, scales it (wheelbase about 1.26 m) and renames materials |
| `people_sdf.py` | Hall travellers, as groups of `name__part` nodes |
| `gen_hall.py` | Rewrites the `<svg id="hallSvg">` block of `index.html` (hall seen from outside, then inside) |
| `build_single.py` | Builds the one-file release (see [DEPLOYMENT.md](DEPLOYMENT.md)) |

Coordinate convention: glTF, `x` = side, `y` = up, `z` = forward.

```bash
cd v6
python3 tools/rider_sdf.py     # writes models/rider.glb
python3 tools/people_sdf.py    # writes models/people.glb
python3 tools/gen_hall.py      # rewrites the hall SVG in index.html
```

`gen_hall.py` edits `index.html` in place. Keep a copy if you have hand-edited the hall.

## Blender scripts (`v6/blender/`, `v6/tools/blender/`)

| Script | Role |
| --- | --- |
| `lib.py` | Shared helpers (clean dedicated scene, mesh helpers, export) |
| `rider.py`, `kit_buildings.py`, `kit_nature.py`, `kit_landmarks.py` | One kit each |
| `all.py` | Runs the four kit scripts in turn |
| `Lancer atelier Blender.command` | macOS watcher that runs queued jobs in headless Blender |
| `tools/blender/faune_blender.py` | Animal kit: voxel remesh, smoothing, decimation, zone colouring |
| `tools/blender/json2glb.py` | Converts a JSON mesh dump to GLB with clustering |

Heads-up: these scripts still hold absolute paths from the author's machine
(`~/dev/portfolio-v4/...`, `/Users/annabelle/dev/annabelle-portfolio-blender`).
Edit `D` in `all.py`, `ROOT` in `lib.py`, `OUT` in `faune_blender.py` and `B`/`D` in the
`.command` file before running them. A headless run looks like:

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P v6/blender/kit_buildings.py
```

`scooter.blend` and `scooter_retro.glb` in `tools/` are the source of the scooter.

## `_dev/`

One-off patch scripts (`patch_*.py`), a triangle counter (`count.py`) and
`preview.html` (a model preview page). They contain absolute paths from the
original build sandbox and are kept for history only.
