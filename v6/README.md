# Portfolio v6

The current version of the interactive portfolio. See the
[root README](../README.md) for the overview and the [docs](../docs/) for details.

## Run it

```bash
python3 -m http.server 8000   # from this folder
```

GLB models are loaded with `fetch`, so a web server is required.

## What changed in v6

- New scooter (from the `scooter_retro` model, imported by `tools/scooter_import.py`) and a rounder rider.
- Shorter roads between stops. Paris (walls) and Skills (signs) scenery fixed.
- Redesigned Sossusvlei postcard (message, address, stamp).
- Jumping from the map: orbital camera move, lower flight over the scenery, parachute kept.
- Road profiles are flat at junctions (no more "sinking" effect).
- Sound: `js/audio.js` (Web Audio, nothing to download). Generative music per country, city / nature / ocean / night-cricket ambience, softer engine. Toggle with the "Sound" button.

## Folder map

| Path | Role |
| --- | --- |
| `index.html` | Page shell and the home-hall SVG (generated by `tools/gen_hall.py`) |
| `js/data.js` | **All content**: profile, UI strings, worlds, cities, panels |
| `js/gl.js` | WebGL2 engine |
| `js/world.js` | Lighting moods, road network, scenery builders |
| `js/models.js` | GLB loader and mesh stamping |
| `js/rider.js` | The rider and scooter mesh |
| `js/ride3d.js` | Ride mode: physics, camera, stops, hall |
| `js/flight3d.js` | Flight cutscene |
| `js/audio.js` | Procedural sound |
| `js/app.js` | Views, language, board, HUD, panels, classic version |
